# Projeto Prático de Desenvolvimento Web - NetBeans

## Descrição
Este projeto tem como objetivo aplicar conhecimentos de desenvolvimento de aplicações web utilizando a IDE NetBeans, frameworks e tecnologias associadas. O trabalho inclui:

- Configuração de servidor Apache Tomcat.
- Consumo de API externa (Correios) para preenchimento automático de endereços.
- Criação de formulários de cadastro com Spring MVC e HTML5/JavaScript.
- Validação de campos do lado do cliente utilizando JavaScript e jQuery.
- Estilização responsiva com Bootstrap 5.

---

## Atividades Desenvolvidas

### Atividade 1 
- Configuração do servidor Apache Tomcat no NetBeans.
- Teste de execução de uma aplicação web simples.
- Folder: AtividadePratica1

### Atividade 2
- Criação de formulário HTML5 para consumo da API de CEP dos Correios.
- Preenchimento automático de campos: rua, bairro, cidade e estado.
- Utilização de JavaScript e Bootstrap para interatividade e estilo.
- Folder: cadastroEndereco

### Atividade 3
- Implementação de formulário de cadastro com Spring MVC.
- Inclusão de campos: nome, sobrenome, email, senha, CEP, rua, bairro, cidade, estado, número e complemento.
- Estilização utilizando Bootstrap 5.
- Folder: cadastroUsuario

### Atividade 4
- Criação de formulário de cadastro HTML5/JavaScript.
- Validação de campos obrigatórios e e-mail usando JavaScript e jQuery.
- Layout totalmente responsivo com Bootstrap 5.
- Folder cadUsuário

---

## Tecnologias Utilizadas
- **IDE:** NetBeans  
- **Servidor:** Apache Tomcat  
- **Frontend:** HTML5, CSS3, Bootstrap 5  
- **Backend:** Spring MVC  
- **JavaScript:** Vanilla JS e jQuery  
- **API Externa:** ViaCEP (Consulta de CEP)

## Como Executar
1. Clone o repositório:
```bash
git clone https://github.com/Pereiraaline/FrameworkDesenvolvimentoSoftware.git

```
2. Abra o projeto no NetBeans.
3. Configure o servidor Apache Tomcat (caso ainda não esteja configurado).
4. Execute cada atividade diretamente pelo NetBeans ou abra os formulários HTML no navegador.
5. Para testar a consulta de CEP, abra o formulário da Atividade 2.
6. Para testar os formulários de cadastro, execute as Atividades 3 e 4.

---

## Funcionalidades
- Consulta automática de endereço por CEP.
- Cadastro de usuários com validação de campos.
- Integração com Spring MVC.
- Layout responsivo utilizando Bootstrap 5.
- Validação de e-mail e preenchimento obrigatório via JavaScript/jQuery.
